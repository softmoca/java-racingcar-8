# 기능 구현 목록

## 자동차

### 생성 및 속성

- [ ] 자동차를 이름으로 생성한다
- [ ] 자동차는 이름을 가진다
- [ ] 자동차 이름은 5자 이하여야 한다
- [ ] 이름이 5자 초과 시 IllegalArgumentException 발생
- [ ] 자동차는 위치 정보를 가진다
- [ ] 자동차의 초기 위치는 0이다

### 이동

- [ ] 전진 조건이 true이면 위치가 1 증가한다
- [ ] 전진 조건이 false이면 위치가 변하지 않는다

### 이름 파싱

- [ ] 쉼표로 구분된 문자열을 여러 개의 이름으로 분리한다
- [ ] 분리된 각 이름으로 자동차를 생성한다

---

## 전진 조건 판단

- [ ] 0~9 사이의 무작위 값을 생성한다
- [ ] 무작위 값이 4 이상이면 true를 반환한다
- [ ] 무작위 값이 4 미만이면 false를 반환한다

---

## 경주 게임 진행

- [ ] 여러 대의 자동차를 관리한다
- [ ] 정해진 횟수만큼 게임을 반복한다
- [ ] 각 라운드마다 모든 자동차에 대해:
    - [ ] 전진 조건을 판단한다
    - [ ] 조건에 따라 자동차를 이동시킨다

---

## 우승자 결정

- [ ] 모든 자동차 중 가장 큰 위치 값을 찾는다
- [ ] 가장 큰 위치에 있는 모든 자동차를 찾는다 (공동 우승 가능)
- [ ] 우승자가 여러 명이면 쉼표로 구분한다

---

## 입력

- [ ] 자동차 이름 입력 안내 문구 출력
- [ ] 자동차 이름들을 입력받는다
- [ ] 시도 횟수 입력 안내 문구 출력
- [ ] 시도 횟수를 입력받는다

---

## 출력

- [ ] "실행 결과" 문구를 출력한다
- [ ] 각 자동차의 상태를 출력한다 (이름 : 위치)
    - [ ] 위치만큼 '-' 문자를 생성한다
- [ ] 각 라운드 사이에 빈 줄을 출력한다
- [ ] 최종 우승자를 출력한다
    - [ ] "최종 우승자 : 이름1, 이름2" 형식
